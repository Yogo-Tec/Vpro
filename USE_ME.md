# How to Use Vpro Billing Software

1. Open `index.html` in your browser.
2. Fill the three editor sections:
   - Company & invoice details.
   - Customer and project details.
   - Payment, notes, and account details.
3. Add invoice rows with **Add item**.
4. Edit any row by typing directly into the table fields.
5. Remove one row with **Remove** or clear every row with **Delete all**.
6. Use **Save XML** to download the invoice data as an XML file.
7. Use **Save As** to download the XML with a custom file name.
8. Use **Upload XML** to load a saved invoice and continue editing.
9. Use **Print** to print or save the professional invoice as PDF from your browser.

## Notes

- Browsers cannot silently write XML files into the repository folder, so the Save actions download XML files to your computer.
- The app also keeps a draft in browser local storage to protect recent work.
- For best print results, use A4 paper and enable background graphics in the browser print settings if available.
